# Brasinha.Digital

Cardápio digital mobile-first da Brasinha Pizzaria & Chopperia, Água Clara/MS.

## Recursos

- Cardápio responsivo para bio do Instagram
- Busca por sabores e ingredientes
- Categorias de pizzas, bordas, burgers, porções, bebidas, cervejas e drinks
- Carrinho simples
- Pedido formatado enviado pelo WhatsApp
- Sem login e sem checkout online
